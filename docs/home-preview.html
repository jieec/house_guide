换色逻辑：不是重新挑一套颜色，而是把原来每个色值按同一规则整体旋转色相—— 浅色阶（#DDECEB → #E7E3F6）只挪色相不动明度， 所以卡片、背景、标签的「浅」完全保留；深色阶（#35635E → #52467B） 同理只换冷暖，对比度反而从 7.4:1 提到 8.2:1。
一处顺手修的：「评估结论」和「按揭测算」两个图标原来都是同一个琥珀色，几乎分不出来； 现在「评估结论」改成藕紫，四个图标形成 靛 → 蓝 → 藕 → 琥珀 的冷暖渐变，既区分得开，也压住了整体的紫调。
