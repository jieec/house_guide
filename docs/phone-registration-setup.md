# 微信手机号授权注册部署说明

## 已实现流程

1. 小程序首先进入 `pages/register/register`。
2. 注册页调用 `auth` 云函数查询当前微信用户是否已注册。
3. 未注册用户点击微信手机号授权按钮，前端只把一次性 `code` 交给云函数。
4. 云函数使用微信开放接口换取手机号，并以当前用户 `OPENID` 作为 `users` 文档 ID 保存。
5. 注册成功后进入首页；所有业务页面会再次查询注册状态，未注册则返回注册页。

## 首次部署

1. 在微信开发者工具中打开云开发控制台，创建 `users` 集合。
2. 将 `users` 集合权限设为客户端不可直接读写；注册资料仅由云函数访问。
3. 右键 `cloudfunctions/auth`，选择“上传并部署：云端安装依赖”。
4. 在微信公众平台配置《用户隐私保护指引》，声明收集手机号的用途。
5. 在小程序后台确认当前主体具备手机号快速验证组件的使用资格和可用额度。
6. 用真机进行首次注册测试。开发者工具模拟器不一定能返回可用于正式接口的手机号凭证。

开发者工具模拟器会显示“开发者工具模拟登录”按钮，用于跳过手机号接口调试业务页面。该按钮根据运行平台动态显示，真机、体验版和正式版均不可见，模拟账号也不会写入云数据库。

## 验收场景

- 新用户打开小程序，只能看到注册页。
- 未勾选隐私协议时，授权按钮不可点击。
- 拒绝手机号授权后，仍停留在注册页。
- 授权成功后进入首页，`users` 集合出现以 `OPENID` 为 ID 的文档。
- 再次打开小程序直接进入首页。
- 从分享链接直接打开房源详情，未注册用户会被送回注册页。
- “我的”页面只展示脱敏手机号。

## 安全说明

- 前端不得上传或修改明文手机号。
- `users` 集合不得开放客户端写权限。
- 当前业务数据仍有客户端直读逻辑；如需防止恶意客户端绕过页面访问公共数据，应进一步把房源查询迁移到带注册校验的云函数。
