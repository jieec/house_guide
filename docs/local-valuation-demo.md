# 本地房产估价演示

本地演示使用完全虚构的房源和固定模拟接口响应，用于验证单套房估价、小区报告、页面状态及 PDF 导出。它不验证真实市场估值精度，也不调用真实模型。正式路径调用失败时不会自动切换演示模式。

## 打开方式

在微信开发者工具中导入项目并完整编译，进入首页的“本地演示”：

- “单套房估价演示”：打开 `/pages/houses/analyze/analyze?demo=1`。
- “小区报告演示”：打开指南并显式进入本地演示，可退出演示回到正常模式。

单套页可以跳转到小区演示，小区演示也可跳回单套页。入口和报告中都会显示“演示数据”；直接进入真实房源页仍使用云接口。首页原有真实数据统计和小程序云 SDK 初始化保留，演示的房源读取与估价流程不依赖它们成功。

新增共享组件在 `app.json` 全局注册，两页亦明确声明。若开发工具热更新时仍保留旧依赖告警，重新编译项目。没有关闭代码依赖过滤或改变云环境配置。

## 可切换的场景

| 场景 | 预期结果 |
|---|---|
| 正常估价 | 采用单价 26,000 元/㎡，90㎡，总价 2,340,000 元 |
| 候选价待复核 | 候选价 28,000 元/㎡，当前采用公式参考价 25,000 元/㎡；总价 2,250,000 元 |
| 模型超时回退 | 无模型候选，明确显示公式参考价及超时原因 |
| 缺少房源面积 | 单套总价显示“暂无”，清空依赖面积的旧金融测算；补录有效面积后重新生成 |
| 市场数据不足 | 无采用价、无总价，不展示为 0 元；可以导出明确的数据不足报告 |
| 接口调用失败 | 展示错误和重试入口，不保留旧价格，不允许导出旧报告 |

小区估价只给参考单价，不计算单套总价。购房目的在本阶段作为业务参数记录，不影响同一资产的市场估价。

## 修改与导出

修改单套面积或购房目的后，旧评估立即失效，必须重新生成。估价加载中、接口错误或报告失效时禁止导出；切换房源或场景后，旧请求不会覆盖新页面。

“生成 PDF 报告”冻结当前 `valuationReport`，不会为导出重新调用模型。采用价与候选价、买方和处置意见、依据、缺失项、版本和报告编号来自同一个快照；待复核意见明确标注未采纳。每页 PDF 都标注演示数据。单套页下方的贷款、税费预算仍为独立示例测算，当前结构化估价 PDF 不将这些预算当作估价结论。

运行下文的样张生成脚本会输出 `output/pdf/单套房估价-演示报告.pdf`。样张和页面均使用同一组虚构数据（26,000 元/㎡、90㎡、234 万元），独立生成时报告编号和时间各自不同。

2. 完整编译，退出本地演示，在“房源”中选择有数据的城市、二手房和小区，再进入具体房源的“分析”。路由为 `/pages/houses/analyze/analyze?id=<真实房源编号>`，不带 `demo=1`；真实页面需主动点击“生成估价报告”。也可在指南中选真实小区后点击“生成小区评估”。
3. 优先选择有单套面积和明确关联小区的房源。后端优先读 `communityId/community_id`；缺少关联 ID 时，按小区名查询并按去掉末尾“市”的城市名过滤，必须唯一匹配 `communities`。估价证据排除目标房源自身，因此小区还应有其他有效价格样本或小区价格参考。不要为测试编造面积或成交记录。
4. 核对返回报告的房源编号、报告编号、模型候选价、采用价、状态和回退原因。真正的模型结构化输出成功要求 `modelEstimate` 和有效 `modelUnitPrice` 非空、`fallbackReason` 为 null，且状态为 `needs_review` 或 `model_estimate`。默认 `maxDeviationRatio=null` 时，`needs_review` 是预期成功状态，页面保留候选价和建议，采用价仍为公式基准；不要为了得到“已采用”而擅自放宽复核门槛。`rule_only` 表示模型没有产出可用候选，只验证了回退流程。
5. 页面完成后点击底部“生成 PDF 报告”。核对 PDF 与页面的房产编号、报告编号、采用价、候选价、面积、总价、建议、证据和版本一致；真实报告的数据模式应为“云端评估结果”，没有演示标记。待复核结果的候选意见仍应明确标注未采纳。

调试器可只查看当前页的 `data.demoMode` 和 `data.valuationReport` 核对来源；真实报告编号格式为 `v_` 加 30 位十六进制字符，不能以编号格式单独证明模型调用成功。`exportPdf()` 成功返回 `{ ok: true, path, valuationId }`；返回成功后仍需实际打开 PDF 检查内容。修改面积或购房目的会使旧报告失效，应重新生成再导出。

正式调用使用 `aiChat` 的 `createEvaluation/getEvaluation`。微信附加的 `userInfo` 和 `tcbContext` 由云函数入口剥离，身份仍取 `cloud.getWXContext().OPENID`，不信任这两类元数据中的身份值；云控制台缺少微信上下文时的 `UNAUTHORIZED` 不能替代模拟器测试。配置、模型调用和 PDF 的真实联调结果需分别记录，演示样张不能作为真实模型验收证据。
