## 第二轮：内嵌真实字体（霞鹜文楷）

用户反馈描述性文字（welcome-desc / section-caption / tool-desc / summary-desc）"太普通"，要求更美观。

### 技术结论（重要）
- **小程序 WXSS 不支持本地字体文件**，`@font-face` 只能 https 或 base64 data URI；`wx.loadFontFace` 同样只接受 https/data URI
- 因此方案 = 子集化 + base64 内嵌到 `styles/fonts.wxss`

### 字体选型
- **霞鹜文楷 Screen（LXGW WenKai Screen）v1.235**，SIL OFL 1.1，可商用
- 来源：npm `lxgw-wenkai-subset`（npmmirror，GitHub 直连被墙）
- 子集：项目 1340 字（含 ASCII/标点），`pyftsubset --layout-features=kern --no-hinting --desubroutinize --flavor=woff2`
- 结果：319KB woff2 → 426KB base64 wxss
- 只有 Regular 一个字重，故所有衬线文字统一 `font-weight: 400`，**禁止 ≥600**（会触发合成粗体，笔画发糊）

### 字体分工（两层）
- **文楷**：page-title / welcome-title / summary-title / empty-title / query-title / sub-title + 所有 desc·subtitle·caption 类（page-subtitle, welcome-desc, section-caption, summary-desc, card-subtitle, tool-desc, list-item-desc, empty-desc, guide 的 cat-desc-small/legend-desc/price-note/tool-note/loan-panel-subtitle）+ 数字（summary-mark, section-count）
- **系统黑体**：按钮、表单 label/input、card-title、section-title、list-item-title、badge、tabBar、所有数值

### 字号微调
- page-title 40→42rpx；body-text 26→27rpx/lh1.85；mini-text 24→25rpx；num-display 48→50rpx
- 描述类统一加 `letter-spacing: .5rpx`、`line-height: 1.7~1.85`，颜色加深到 #465855 / #5E716E（文楷偏细，需提高可读性）

### 包体积处理
- `images/整体背景.png` 2.1MB → 全部 11 个页面改用已有的 `整体背景.jpg`（49KB），16% 透明度下无差异
- `project.config.json` packOptions.ignore 新增：整体背景.png、fonts/、chinese_chars*.txt、extract_chars.py
- 当前预计上传包 **1.05MB**（含字体），上限 2MB

### 风险备注
- 字体只覆盖 1340 字；缺字会按 `--font-serif` 栈回退到 Songti/SimSun（仍是衬线，不会变成黑体）
- 文楷仅用于静态文案，动态数据（楼盘名/小区名）仍走黑体，避免缺字混排
- 若真机上 @font-face 不生效，备选方案是改用 `wx.loadFontFace` + 同一份 base64

原顺序：hero 主视觉 → 快捷工具 → 当前位置
